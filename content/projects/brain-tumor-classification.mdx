## The problem

Reading brain MRI scans takes specialist time, and a first-pass classifier can help prioritise which scans need attention. This project builds that classifier from scratch, as a learning exercise in designing and tuning a CNN rather than relying on a pretrained backbone.

<Callout>Research and educational project only. It is not a medical device and must not be used for clinical diagnosis.</Callout>

## How it works

<Pipeline steps={["MRI scan", "Custom CNN features", "MLP head", "Tumour class + confidence"]} highlight={1} />

A custom convolutional feature extractor feeds an MLP classification head that predicts one of four classes. The workflow: curate the dataset into train/validation/test CSVs, explore the data, train a baseline, run a random hyperparameter search, retrain with the best parameters, then evaluate on the held-out test set. A **Streamlit** app takes an uploaded scan and returns the predicted class with a confidence score.

## Key decisions

<Decisions>
  <Decision title="A custom CNN instead of transfer learning">
    Building the feature extractor from scratch made the effect of each architecture and training choice visible, which was the point of the project.
  </Decision>
  <Decision title="Systematic tuning with skorch">
    Wrapping the PyTorch model with skorch made scikit-learn's random search available. Hyperparameters were tuned systematically instead of by hand.
  </Decision>
</Decisions>
