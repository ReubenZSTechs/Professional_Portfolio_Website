## The problem

Growing advice is scattered across research papers that home growers never read, and land-restoration teams have no quick way to see which parcels are worth restoring. Plantatio serves both: **home growers** looking after a few plants, and **restoration operators** managing land at scale.

It won **1st place at Technofest UBM 2026**.

## How it works

<Pipeline steps={["Question", "Decompose", "Text-to-Cypher", "Neo4j subgraph", "Reason", "Answer + evidence"]} highlight={2} />

A four-node LangGraph pipeline over typed state:

1. **Decompose**: the LLM splits the question into sub-questions.
2. **Retrieve**: each sub-question becomes a Cypher query against Neo4j, with the live graph schema in the prompt and a keyword fallback when the generated query finds nothing.
3. **Reason**: step-by-step reasoning over the retrieved subgraph.
4. **Answer**: a grower-facing reply plus the facts it came from, so every answer can be expanded to show its evidence.

Next to the assistant: a **ResNet-50 leaf-disease classifier** that ranks diagnoses from a photo, a **Qwen2.5-VL** model that compares baseline and current satellite images, and a map-based console that ranks restoration parcels.

## Key decisions

<Decisions>
  <Decision title="A knowledge graph instead of plain vector RAG">
    62 tomato-agronomy research papers were reduced to 2,061 typed subject–relation–object triplets: 10 node labels (Disease, Pest, Nutrient, Symptom, Solution and more) and 36 relationship types. A graph can answer multi-hop questions ("which nutrient deficiency causes this symptom, and what fixes it?") that chunk retrieval struggles with.
  </Decision>
  <Decision title="One model, four roles">
    A single Llama 3.1 8B Instruct model serves decomposition, text-to-Cypher, reasoning and answering, each with its own decoding budget. It is loaded on first use so the API starts instantly. The LLMs were fine-tuned with SFT and RL using LoRA on LLaMA-Factory and Unsloth.
  </Decision>
  <Decision title="Fail honestly">
    Every model path degrades with an explicit message. With no knowledge graph, no classifier checkpoint or unsupported hardware, the API returns a clear 503 instead of making up a diagnosis or an answer.
  </Decision>
</Decisions>
