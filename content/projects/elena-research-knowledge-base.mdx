## The problem

Papers I read for one project are useful again months later, but only if I can find them and remember what they said. Elena is the [A.T.H.E.N.A](/projects/athena) agent that stores research papers and makes them retrievable for future work. It complements [Arthur](/projects/arthur-research-paper-summarizer), which summarises papers one at a time.

## How it works

Elena is built on the shared A.T.H.E.N.A workspace: a FastAPI + LangGraph backend with retrieval, database and pipeline modules, a frontend, and the shared LoRA → GGUF → Ollama training and serving tools.
